# Work Around

A modern and lightweight Kanban-style task management application built using HTML, CSS, and JavaScript. Work Around helps users organize tasks efficiently through an intuitive drag-and-drop interface inspired by agile workflow boards.

## 🚀 Features

- 📋 Three-stage workflow management
  - To Do
  - In Progress
  - Done

- ➕ Create new tasks with:
  - Task title
  - Task description

- 🖱️ Drag-and-drop task movement between columns

- 🗑️ Delete tasks instantly

- 🎨 Clean dark-themed user interface

- 📱 Responsive and lightweight design

## 📸 Overview

Work Around provides a visual workflow board that allows users to:

1. Add new tasks through a modal form.
2. Track task progress across different stages.
3. Reorganize tasks using drag-and-drop interactions.
4. Remove completed or unnecessary tasks.

## 🎯 How It Works

### Creating a Task

- Click the **Add New Task** button.
- Enter a task title.
- Optionally add a description.
- Click **Add Task**.

### Moving a Task

- Drag a task card.
- Drop it into any workflow column.

### Deleting a Task

- Click the **Delete** button on any task card.
